# 劳动仲裁维权助手（Arbitration Assistant）

> CDS 550 Final Project —— 把劳动者一段大白话，翻译成能立案的仲裁主张，并算出大概能要多少钱。
> **规则内核不依赖任何大模型**：钱和时效必须算得准、算得可复现。

## 快速开始（五条命令）

```powershell
# Windows PowerShell（本机 pytest 装在项目内 .libs，见下方"环境说明"）
$env:PYTHONPATH = "src"
python -m arb.cli "2020年3月1日入职，月薪9000，一直没签书面合同。2024年5月20日主管口头说不要我了，还有5天年假没休。"
python -m arb.web            # 打开 http://127.0.0.1:8765
python -m arb.demo           # 三屏演示：能算清的 / 说不清的 / 不该它管的（录视频用）
python -m arb.pdf "同上那句话" -o 报告.pdf   # 导出 PDF（自检不过会返回退出码 1）
```

## 环境说明

- 只要 **Python 3.10+ 标准库**，不装任何第三方包也能跑（网页版、CLI、演示模式、法条检索都是 stdlib）
- **全程不需要联网**：法条已落成本地 jsonl，模型层有 key 才走，没 key 走规则抽取——断网也能完整演示
- 本机沙箱禁止写 site-packages，所以 pytest 装在项目内：

```powershell
pip install --target .libs pytest pytest-cov
$env:PYTHONPATH = ".libs"; python -m pytest -q --cov=arb
```

## 已实现的规则（附法条）

| 项目 | 口径 | 依据 |
|---|---|---|
| 工龄折算 | 满 1 年 1 个月；6 个月以上不满 1 年按 1 年；不满 6 个月半个月 | 劳动合同法 47 |
| 经济补偿 N | 月均工资 × 折算月数；高于社平 3 倍时按 3 倍封顶且年限≤12 年 | 劳动合同法 47 |
| 违法解除 2N | N × 2，与 N 不并用 | 劳动合同法 87 |
| 二倍工资 | 用工满 1 个月次日起至补签前一日，最多 11 个月 | 劳动合同法 82 |
| 加班费 | 日工资 = 月工资 / 21.75；150% / 200% / 300% | 劳动法 44 |
| 年假 | 5 / 10 / 15 天档位；未休按额外 200% | 年休假条例 5、实施办法 10 |
| 时效 | 1 年；欠薪在劳动关系存续期间不受限，终止后 1 年内 | 调解仲裁法 27 |

## 口径说明（有争议的地方）

- **二倍工资不足一个月怎么算**：默认"整月计，不足一月不计"（保守）；可在 `Policy(double_wage_round_up_partial_month=True)` 切换为"不足一月按一月"。
- **年假的"累计工作年限"**含此前单位，不只看本单位。
- **N 与 2N 不并用**：判了违法解除就只算 2N，不再叠加 N。

## 不做的事

不定罪、不预测胜诉率、不教人伪造证据、不替代律师（给 12348）。
工伤认定、社保补缴、公积金一律**只指路，不结论**。

## 消融实验：拆掉哪个部件，分数掉多少

命令：`PYTHONPATH=src python -m scripts.ablation` → `docs/ablation.md`

| 臂 | 金额命中 | 该算未算（追问/拒答） | 输出引用 | 可核验 | 探针判对 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A 裸算（不查库/不拒答/不追问） | 5/50 | 0 | 143 | 0/143 | 0/7 |
| B + 范围拒答 | 5/50 | 0 | 143 | 0/143 | 5/7 |
| C + 缺口追问 | 30/50 | 20 | 0 | 不接法条库 | 7/7 |
| D 全套（现行） | 30/50 | 20 | 57 | 57/57 | 7/7 |

一句话：**不追问就猜（只对 5/50）、不接库就核不了（143 条引用无一可验）、不拒答就把工伤当仲裁算**。
"纯大模型直答"那一臂本机没有 key，**留空不编**；`scripts/llm_baseline.py` 配 key 后可补齐。

## 网页版（推荐演示用）

```powershell
$env:PYTHONPATH="src"
python -m arb.web
```

打开 http://127.0.0.1:8765 ：

- 输入一段大白话 → 逐项金额 + 法条原文（可展开）+ 仲裁时效倒计时 + 抗辩预演
- **案件完整度地图**：9 项信息一眼看全，缺的标红并可直接点着补进输入框
- **证据清单标注谁举证**：单位掌握的证据（考勤、工资发放记录、解除决定）用橙色标出，可要求单位提供
- 不会说？下面有 **35 个关键词芯片**，点一下就插进输入框并解释"这是什么"
- 工伤 / 社保补缴 / 公积金会自动拒答，并告诉你该去哪、带什么
- `/pdf` 下载 PDF（第一页就能直接打印/发给家人），`/print` 网页版打印，`/report` 下载 Markdown，`/application` 生成仲裁申请书草稿

> PDF 是纯标准库手写的：用 PDF 标准中文字体 `STSong-Light`，**不嵌字体**，靠阅读器替换成系统宋体，所以文件只有 9 KB；个别极简阅读器若显示异常，用网页版打印保底。文本层可复制可搜索（`tests/test_pdf.py` 按 UCS2 解码校验过）。

不需要任何第三方依赖（Flask 都不装），有 Python 就能跑。

## 隐私

- 故事只在内存里算，不落库、不写日志（`web.py` 只记录路径，不记录表单内容）
- 演示时建议用脱敏故事；真实用户测试前先说明"不要填真名真公司"
