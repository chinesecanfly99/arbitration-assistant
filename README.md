# 劳动仲裁维权助手（Arbitration Assistant）

> CDS 550 Final Project —— 把劳动者一段大白话，翻译成能立案的仲裁主张，并算出大概能要多少钱。
> **规则内核不依赖任何大模型**：钱和时效必须算得准、算得可复现。

## 它回答四个问题，不止"多少钱"

| 问题 | 谁回答 | 落点 |
| --- | --- | --- |
| 这件事**归不归**仲裁管？ | `scope.py` 受案范围 + 红线拒答 | 不归的指路（工伤/社保/公积金），索要胜诉率的当场拒 |
| 你现在**够不够格**申请？ | `gates.py` 三层闸门 | 一事不再理 / 跨城市管辖 / 退休返聘 / 在校实习 / 时效 |
| **能主张多少钱**？ | `calc.py` + `deadline.py` | 逐项金额、法条原文、时效倒计时 |
| **值不值得去、去哪、带什么**？ | `worth.py` / `venue.py` / `materials.py` | 六维值得性、六条立案路径、材料清单与谁举证 |

## 环境说明

- 只要 **Python 3.10+ 标准库**，不装任何第三方包也能跑（网页版、CLI、演示模式、法条检索都是 stdlib）
- **全程不需要联网**：法条已落成本地 jsonl，模型层有 key 才走，没 key 走规则抽取——断网也能完整演示
- **Windows / macOS / Linux 行为一致**：输出编码在入口统一切成 UTF-8（`arb/console.py`），
  源码里没有任何写死的盘符或家目录（`tests/test_console.py` 扫源码强制这一点）

## 已实现的规则（附法条）

| 项目 | 口径 | 依据 |
|---|---|---|
| 工龄折算 | 满 1 年 1 个月；6 个月以上不满 1 年按 1 年；不满 6 个月半个月 | 劳动合同法 47 |
| 经济补偿 N | 月均工资 × 折算月数；高于社平 3 倍时按 3 倍封顶且年限≤12 年 | 劳动合同法 47 |
| 违法解除 2N | N × 2，与 N 不并用 | 劳动合同法 87 |
| 二倍工资 | 用工满 1 个月次日起至补签前一日，最多 11 个月；**按月计算** | 劳动合同法 82 + **司法解释（二）6** |
| 加班费 | 日工资 = 月工资 / 21.75；150% / 200% / 300% | 劳动法 44 |
| 年假 | 5 / 10 / 15 天档位；未休按额外 200% | 年休假条例 5、实施办法 10 |
| 时效 | 1 年；欠薪在劳动关系存续期间不受限，终止后 1 年内 | 调解仲裁法 27 |
| 时效抗辩 | 仲裁期间未提时效抗辩、诉讼阶段再提的，法院不支持 | **司法解释（二）20** |
| 退休返聘 | 原"一律按劳务关系"条款（解释一 32 条第 1 款）已废止，改看是否已享受养老保险待遇 | **司法解释（二）21**、司法解释（一）32 |
| 一方已履行的和解协议 | 不违反强制性规定且无欺诈/胁迫/乘人之危的，认定有效 | 司法解释（一）35 |

> 为什么专挑司法解释也入库：**《劳动合同法》第 82 条没写"按月计算"**。
> 以前只引 82 条，条号是真的、结论也是对的，但出处不对——评审一查原文就发现你没引到真正规定的地方。
> 这就是我们说的"引得到 ≠ 引得准"。

## 口径说明（有争议的地方）

- **二倍工资不足一个月怎么算**：司法解释（二）第 6 条是"按该月实际工作日折算"。本单默认取**更保守**的口径
  （整月计、不足一月不计），并在输出的 `note` 里写明本单用的是哪种；可在 `Policy(double_wage_round_up_partial_month=True)`
  切到"不足一月按一月"。三种口径都能算，选哪种说清楚，不藏在代码里。
- **年假的"累计工作年限"**含此前单位，不只看本单位。
- **N 与 2N 不并用**：判了违法解除就只算 2N，不再叠加 N。
- **3 倍封顶用哪个数**：用`data/city/` 里该城市的上年度职工月平均工资，带出处与核验日；
  城市没收录就**明说没覆盖、不套用别的城市数字**，绝不拿深圳的数去算成都的案子。
- **跨城市怎么办**：叙述里同时出现两个已覆盖城市（"在深圳上班、公司注册在北京"）时，
  只提示"两边都有管辖权、只能挑一个"，不给结论——挑哪边是当事人的决定，不是程序的决定。

## 不做的事

不定罪、不预测胜诉率、不教人伪造证据、不替代律师（给 12348）。
工伤认定、社保补缴、公积金一律**只指路，不结论**。
值得性打分只用于排先做什么，**不是胜诉概率**。

## 三道闸门：为什么"能算钱"不等于"能申请"

算得准只回答"多少"，回答不了"我现在能不能去立这个案"。下面任何一条踩中，屏幕上那个总额都是误导：

| 层 | 问什么 | 命中后的行为 |
| --- | --- | --- |
| 第一层 受案范围 | 归不归《调解仲裁法》第二条管？是红线请求吗？ | 不归 → 拒答并指路（工伤/社保/公积金）；索要胜诉率 → 当场拒 |
| 第二层 资格 | 主体适格吗？一事不再理吗？重复申请吗？时效过没过？管辖在哪？ | 硬障碍 → `blocked`，**不给金额**；软提醒 → `warn`，仍给金额但列在最前面 |
| 第三层 口径 | 3 倍封顶和一裁终局线用的是哪个城市的数？核验日是哪天？ | 只做提示：数字从哪来、什么时候该重新核 |

五类探针（都写进了 `tests/test_city_gates.py`）：一事不再理、跨城市、退休返聘、在校实习、程序在途。

## 值得性六维：不是胜诉率

| 维度 | 权重 | 它在问什么 |
| --- | ---: | --- |
| 标的额与成本比 | 25% | 跑一趟的时间成本会不会超过收益 |
| 证据强度 | 25% | 关键事实有没有书证撑着（没上传材料时按中性算，不判 0） |
| 一裁终局影响 | 10% | 是否在当地一裁终局线内（单位不能起诉，对劳动者有利） |
| 执行可能性 | 15% | 单位还在不在经营，胜诉后能不能拿到钱 |
| 替代路径优越性 | 10% | 欠薪金额不大时，12333 监察是不是比仲裁快 |
| 时效剩余 | 15% | 还剩几天，是不是该立刻递 |

结论三选一：**建议仲裁 / 可以仲裁但有更快的路 / 先别急着提交**。
分数只用来排"先做哪件事"，页面上明确写着"这不是胜诉率"，也不预测裁判结果。

## 隐私与边界

- 故事只在内存里算，不落库、不写日志（`web.py` 只记录路径，不记录表单内容）
- 模型/图片读数默认不进计算，且只在页面会话里存在；确认与否都不落盘
- 演示时建议用脱敏故事；真实用户测试前先说明"不要填真名真公司"
