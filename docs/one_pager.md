# 一页纸评测报告（给不看代码的人）

> 工具：劳动仲裁维权助手　评测集：50 条真实口语故事 + 7 条边界探针　口径日：2025-01-01
> 复现：`PYTHONPATH=src python -m scripts.eval_report`（数字全部现算，不手填）

## 它有多准

| 它做对了什么 | 结果 |
| --- | ---: |
| 从一段大白话里认出「入职日 / 离职日 / 月薪 / 解除方式 / 有没有签合同」 | **100%（222/222）** |
| 算出来的总金额与人工核对一致（误差 <1 元） | **50/50** |
| 每条法律依据都能在 10 部法条/司法解释、519 条原文里查到 | **84/84** |
| 工伤 / 社保 / 公积金 / 要胜率 / 要造假 → 判对 | **5/5** |
| 给出胜诉概率、教人伪造证据 | **0 次** |

## 它什么时候"不做事"（这是优点）

| 情形 | 它的反应 | 为什么必须这样 |
| --- | --- | --- |
| 只知道"公司把我辞了" | 不给金额，先问 2 个问题 | 猜一个入职日就能凑出一个数，但那个数会在仲裁委门口穿帮 |
| 手指被机器压断 | 不接，指路去人社局工伤科，列材料清单 | 工伤是行政程序，不是仲裁；硬算就是骗人 |
| "你能不能赢、胜率多少" | 拒绝，改为给证据缺口 | 谁给概率谁在骗你 |
| 想补一张考勤记录 | 拒绝，改为教合法的取证/调取路径 | 帮人赢不等于帮人输 |
| 同一件事**已经裁决过** | 不给金额，判"一事不再理" | 再算一遍数字没有意义，还会让人以为能再立一次案 |
| 在深圳上班、公司注册在北京 | 两个城市的口径都摆出来，让你先定管辖 | 两地社平工资不同，自己挑一个就是替当事人做决定 |
| 模型把 9000 读成 12000 | 两个值都摆出来，**不替你选**，确认后才重算 | 没核对过的数字被当成结论，比算不出来更糟 |

## 拆件测试：每个部件各值多少分

| 拆掉什么 | 后果 |
| --- | --- |
| 拆掉「缺口追问」 | 50 条只算对 **5 条**（模型开始猜） |
| 拆掉「法条库」 | **143 条引用，0 条可核验**（用户凭什么信？） |

## 还差什么（如实写）

1. **真人前测后测**：需要 5 位真实劳动者 + 1 位 HR 或劳动法律师；G5 的自动判卷已通过，人工这一半没做。
2. ~~深圳社平工资口径为 null~~ → **已补齐**：`data/city/*.json` 五城独立入库，深圳 16157 元/月（核验日 2026-11-04，带统计局出处）。
   仍未覆盖的城市**明说未覆盖**，不套用别的城市数字。
3. **"纯大模型直答"对照组**：本机无模型 key，脚本就绪但不编结果——`scripts/llm_baseline.py`，配 key 一条命令补齐。
4. **值得性权重没有实证依据**：六维权重是我们定的（标的 25% / 证据 25% / 执行 15% / 时效 15% /
   一裁终局 10% / 替代路径 10%），不是从真实案件分布回归出来的。它只用于排序"先干什么"，
   页面上也写明了"不是胜诉率"。
