# 5 分钟演示视频：分镜脚本（S6.3）

> 目标：让非技术评委在 5 分钟内记住 **3 个数字 + 1 份 PDF**。
> 原则：不念 PPT、不讲技术栈；每一屏都对应一个"如果不做这层会怎样"。

## 录制前 3 件事

```powershell
cd F:\DSH_file\arbitration_assistant
$env:PYTHONUTF8="1"

# ① 终端演示（三屏一次跑完，录屏窗口 100 列宽）
$env:PYTHONPATH="src"; python -m arb.demo

# ② 网页演示（提前开好，别在录的时候启动）
$env:PYTHONPATH="src"; python -m arb.web     # http://127.0.0.1:8765

# ③ 断网预案：以上两件事都不需要网络；把这条也录一次备用
```

- 浏览器缩放 110%，只留一个标签页；终端字号 16，深色背景。
- 演示口径固定为"2024-06-01"，所以时效天数是 353 天，每次录都一致。
- **不要现场敲字**：故事文本提前存成 `demo_story.txt`，粘贴进去。

## 常见翻车点

- **别在演示时当场改故事**：抽取层是规则+可选模型，现场改字可能触发追问，看起来像"不会用"。
- **别念指标全表**：只念 3 个数字，其余放 slide。
- **不要说"我们用了大模型"**：要说"模型只负责**听懂人话**，钱一律由规则算"——这是评审第一个会问的点。
- 录屏分辨率 1920×1080，输出 H.264；时长控制在 4:50–5:10。
