# 劳动争议案例训练与批量检测

## 数据与训练

- 使用 STARD 的 1,543 条脱敏法律咨询。以标注中是否含劳动合同、劳动争议、工资、工伤等法条作为“劳动相关”的评测标签。标签用于咨询主题识别。 [STARD 数据说明与 MIT 许可](https://github.com/oneal2000/STARD/blob/bae10e1f358685446c3af4b15e7b94724f83bc9e/Data%20Statement.md)
- 另将 34 个最高人民法院公开案例改写为匿名案情摘要，保留来源和检查目标。24 个开发样本参与训练，按发布来源保留 10 个案例用于复测。每案另生成 11 个断句、语气词或同义说法变体，共 374 条变体。 [最高法劳动人事争议第二批](https://www.court.gov.cn/zixun/xiangqing/319151.html) · [第三批](https://www.court.gov.cn/zixun/xiangqing/401172.html) · [第四批](https://www.court.gov.cn/zixun/xiangqing/462311.html) · [指导性案例 237–240](https://www.court.gov.cn/zixun/xiangqing/450651.html)
- 训练了本地字符特征分类器。训练用 1,079 条咨询和 24 个开发案例，另用 231 条咨询选阈值，保留 233 条咨询做最终评测。项目保存权重、样本摘要和指标，训练用咨询原文来自固定上游版本。DeepSeek 继续作为页面可选的对比服务。

## 复测结果

| 检查 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 开发案例的主题识别和指定处理分支 | 11 / 24 | 24 / 24 |
| 按发布来源留出的案例 | 2 / 10 | 10 / 10 |
| 口语和断句变体 | 143 / 374 | 374 / 374 |

检查目标包括是否识别预期事项、是否进入需要的核对分支，以及是否在前置条件缺失时抛出确定总额。通过这些检查表示满足注明的目标。各金额和裁判结论仍受个案事实影响。

233 条留出咨询中有 13 条标注为劳动相关。本地分类器识别出其中 12 条，另有 1 条误报。规则识别出 13 条，另有 3 条按数据集标签计为误报。两者合并后没有增加正确识别。分类器用于离线评测，生产继续使用规则和本地法条。

## 本轮调整

- 平台用工及关联公司案件先列出实际管理、自主接单或定价、签约主体、工资支付等因素，再分别给出材料和处理方向。
- 二倍工资的可计算期间止于实际用工结束。已有其他书面协议、存在拒签或劳动关系待确认时，先核对这些前置条件。短于一个月的未签期间在给出实际工作日后单独试算。 [劳动争议司法解释（二）第 1–9 条](https://www.court.gov.cn/zixun/xiangqing/472691.html) · [最高法指导案例 179 号](https://www.court.gov.cn/shenpan/xiangqing/364631.html)
- 竞业限制先核对岗位接触的保密事项、约定范围和补偿。工伤待遇和社保垫付分开核对已认定事项、鉴定决定及支付凭据。 [劳动争议司法解释（二）第 13–15 条](https://www.court.gov.cn/zixun/xiangqing/472691.html) · [第四批劳动人事争议典型案例](https://www.court.gov.cn/zixun/xiangqing/462311.html)

## 仍需改进

- 留出咨询只有 13 条劳动相关题，主要用来筛掉明显不适合上线的模型。后续应增加来源独立、由人工核标的劳动咨询，覆盖更多地区、工种、方言和真实语音转写。
- 二倍工资跨多月、末段不满整月的试算仍使用整月近似。精确折算需要逐月工资及末段实际出勤日。地区基数和地方办事路径的覆盖也仍有限。
- 目前的程序化检查主要覆盖争议识别、核对方向和避免过早出金额。行政待遇、管辖、举证、时效中断与应对不同对方主张，还需要更多独立案例和逐项人工审核。

## 复现

在项目根目录运行。训练脚本接受 STARD 的原始 data/queries.json。可用 --summary 输出固定数据哈希、拆分数量及检测指标。

```powershell
$env:PYTHONPATH = 'src'
python -m scripts.audit_official_cases
python -m scripts.train_labor_topic "C:/data/queries.json" --revision bae10e1f358685446c3af4b15e7b94724f83bc9e
python -m scripts.train_labor_topic --query "我在平台送外卖，公司每天安排班次"
```
