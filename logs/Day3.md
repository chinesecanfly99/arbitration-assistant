## 今天最重要的三件事

1. **G3 门禁没有通过，而且我把它标成"未通过"。** 抽取 F1 = 84.0%，门槛是 85%，差 1 个点。差的这 1 个点全在「解除方式 54%」和「离职日期 70%」上——这两项直接决定 N 还是 2N。自己给自己放水，答辩现场一定会被问穿。
2. **"不会问"才是真痛点，不是"没钱"**。今天把 35 个法律术语做成芯片，用户点一下就有话说。这个功能看起来像 UI 小活儿，实际是整个项目最贴题的一步——讲师四步法的第一步"识别问题"，很多组会跳过它。
3. **前端故意不用框架**。这台机器装不了包（`pip install` 到 site-packages 报 WinError 5），如果非要用 FastAPI/Streamlit，今天一行界面也跑不出来。纯 stdlib 的结果是：任何一台有 Python 的电脑，`python -m arb.web` 就能演示。

## 现在的真实水位（不许美化）

- 会算钱：规则内核 99% 覆盖、40+ 条单测、2N/N/二倍工资/加班费/年假/欠薪都对。
- 会引法：88/88 引用通过核验，每条都能点开看原文。
- 会拦：工伤/社保/公积金三类指路，超范围不给金额，红线自查 0 条。
- **不会的**：听懂"我被优化了""试用期没过就把我踢了"这类口语——只抽得出 54% 的解除方式。
